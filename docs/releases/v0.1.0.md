# AgentQuest v0.1.0

Milestone 1 closes with a complete manual, deterministic game. Forgotten
Vault is a fixed dungeon with two independently playable routes. The player
collects tools and treasure, then returns to the exit.

- Play in the pixel-art browser interface or the terminal.
- Move, inspect, pick up items, use items, and interact through the same
  deterministic engine. The server controls turns, collision, health,
  inventory, and victory.
- The FastAPI interface provides independent sessions, restart, public
  observations, and idempotent action retries. The browser displays only
  visible and previously discovered map information.

## Verification

- 76 pytest tests passed with warnings treated as errors.
- Three Chromium integration tests passed, covering both routes to victory,
  trap defeat, independent sessions, mobile and desktop layouts, and recovery
  from stale turns and dropped responses.
- The [reproducible demo](../milestone-1-demo.md) includes setup commands,
  a manual walkthrough with expected results, and both test commands.

## Known limitations

- The release contains one fixed map. Browser automation covers Chromium,
  with mobile checks using an emulated viewport.
- Sessions and retry receipts live in one server process. They are lost on
  server shutdown or reload. The API has no authentication or session expiry.
- After restart, a request from the previous run that reaches the server for
  the first time can still execute if its expected turn matches the reset game.
  Previously processed request IDs remain protected. Track run identifiers
  as a follow-up before issuing agent commands across restarts.
- LLM integration begins in Milestone 2.
